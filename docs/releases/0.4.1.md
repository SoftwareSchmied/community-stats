# Community Stats 0.4.1

A single failed request to GitHub or Home Assistant Analytics no longer makes all sensors of that source unavailable. After a connection error or a rate limit, the **last complete values and their attributes stay visible for up to 24 hours**, or three update intervals if that is longer. The source status sensor still shows the error, and the last-successful-update sensor shows how old the values are. Dashboards that group versions by attributes such as `release_tag` keep their data during short outages.

Configuration errors are unchanged: a missing repository, an invalid token or no matching release files make the source unavailable immediately. Before the first successful update, sensors remain unavailable as before.

Failures and recoveries are now written to the Home Assistant log once per change, including the HTTP status or network error, so outages can be traced afterwards.

Update through HACS/Marketplace and restart Home Assistant. Entity IDs and histories are unchanged.
