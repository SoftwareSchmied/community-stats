# Community Stats 0.4.0

GitHub download sensors now select the **latest X published releases with matching download files**, instead of the releases with the most downloads. New releases can enter the selection with zero downloads. The default is ten; the existing version-count setting and prerelease option still apply. Installation statistics continue to select the most commonly installed versions.

Existing version sensors keep their identities and histories. GitHub version sensors expose `in_current_selection` and `published_at` so dashboards can show only the latest selection. An optional [Auto Entities graph example](https://github.com/SoftwareSchmied/community-stats/blob/main/examples/latest-downloads.yaml) follows that selection automatically.

Update through HACS/Marketplace and restart Home Assistant. The next permitted GitHub refresh fills the new selection; manual refresh continues to respect the anonymous queue and API limits. Cached values from older versions remain usable while waiting. Download totals still cover all matching published releases.
