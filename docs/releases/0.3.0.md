# Community Stats 0.3.0

GitHub projects without a token now take turns: this Home Assistant instance updates one project's GitHub statistics every **61 minutes**. Ten anonymous projects are each updated about every **10 hours 10 minutes**. Projects with a token keep their configured interval, as does Home Assistant Analytics.

The queue and next permitted slot survive restarts. Previously fetched values remain visible while waiting, with their original last-success timestamps. Before the first fetch, sensors are unavailable and show a waiting source status. Manual updates and retries cannot jump the queue. Other applications sharing the public IP can still consume GitHub's quota; existing quota checks remain active.

Update through HACS/Marketplace and restart Home Assistant. Existing projects automatically use the appropriate schedule according to whether a GitHub token is configured. On the first update from an earlier release, anonymous projects without a stored observation become available as their turns arrive. Setup discovery uses separate API requests subject to the same limits.

Includes regression coverage for rotation timing, restart fairness, manual refresh, token changes, independent Analytics updates and preserved sensor identities. See [validation details](https://github.com/SoftwareSchmied/community-stats/blob/main/docs/validation.md).
