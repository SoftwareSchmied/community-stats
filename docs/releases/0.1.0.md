Community Stats adds Home Assistant sensors for reported integration installations and GitHub release asset downloads.

- Core integrations: reported installation totals.
- Custom integrations: totals and exact version adoption.
- Cards, themes and other public repositories: downloads of selected release files.
- Stable version sensors that keep their identities when rankings change.
- Optional GitHub token, shared requests and automatic rate-limit recovery.
- English and German setup, source diagnostics and dashboard examples.

Requires Home Assistant 2026.10 or newer. Add the repository to HACS / Marketplace as a custom integration repository until catalog inclusion is complete. Download `community_stats.zip` for manual installation into `config/custom_components/community_stats/`.

Installation counts cover voluntary Home Assistant Analytics reports. Downloads count release-file requests, not active users. Recording starts when the sensors are enabled; past version adoption is not imported.
