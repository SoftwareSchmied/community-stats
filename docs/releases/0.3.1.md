# Community Stats 0.3.1

The top-version count and update interval now use editable number boxes, making the selected values visible during setup and configuration.

Field explanations use Community Stats itself as a consistent example:

- Integration domain: `community_stats`
- GitHub repository: `SoftwareSchmied/community-stats`
- Release filename: `community_stats.zip`

The forms also explain `*.zip`, one filename or pattern per line, empty fields and the 61-minute GitHub rotation without a token.

A single release asset is prefilled automatically. If there are multiple assets, the filename declared in the repository's HACS configuration is proposed only when that file exists in the release. Ambiguous selections stay empty, and every proposal can be changed or cleared. GitHub has no universal release filename.

Update through HACS/Marketplace, restart Home Assistant and reopen the configuration dialog. Existing project settings and sensor histories are preserved.
