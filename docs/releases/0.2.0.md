Community Stats now includes GitHub sensors for stars, forks, watchers, total issues and open issues, alongside installation and download statistics.

- Watchers count actual repository subscribers, not GitHub's legacy alias for stars.
- Issue totals include open and closed issues. Pull requests are excluded from both issue counters.
- Repository statistics work without release assets. Leave the download filename patterns empty to disable download sensors.
- Issue search has its own quota handling and status; a search limit does not hide repository or download values.

The expanded validation also identified and fixed configuration issues:

- Removing or replacing a token removes its original copy from config data. Previously overridden copies are cleaned up on load.
- Repository and token option changes are applied together before reloading.
- Choosing downloads only after a failed setup clears the earlier integration selection.
- Malformed source documents show a validation error instead of interrupting setup.

Existing sensor identities and version history are preserved. Update through HACS / Marketplace and restart Home Assistant.
